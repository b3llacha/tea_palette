# Tea Palette
Bella Cha’s consumer product case study portfolio. The latest reference sets the format: cream paper, blue porcelain drawings, centered search, outlined study buttons, and an illustrated footer border. Four products open their details in place.

## Run locally
Requires Node.js 18 or newer. No package installation needed.

```sh
npm run dev
```
Open http://localhost:5173.

## Build
```sh
npm run build
```
Deploy the contents of `dist/` to any static host. Google Fonts are optional; local serif and sans-serif fallbacks work offline.

## Case study materials
The porcelain art, logo ornament, and footer border are CSS crops of the latest supplied screenshot. The fourth teapot is a CSS crop of the earlier tea illustration sheet. No generated illustrations are used. All six earlier supplied images remain in the “Our story” visual palette gallery.

Search filters the collection by product name, focus, or study description. Select a tea to open its study; previous/next buttons navigate the collection. “The collection” or Escape returns to the landing screen. The layout fits the viewport on desktop and portrait phones; long details can scroll within their panel.

Disney+ and TruFru redesigns, Beli and Duolingo slide decks, and LinkedIn/email/résumé details remain placeholders pending final assets. No scores, results, or external prototype links have been invented.

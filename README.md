# Tea Palette
A responsive consumer product case study portfolio. Cream paper, botanical green, original tea line art, and four illustrative product covers.

## Run locally
Requires Node.js 18 or newer. No package installation needed.

```sh
npm run dev
```
Open http://localhost:5173.

## Build
```sh
npm run build
```
Deploy the contents of `dist/` to any static host. Google Fonts are optional; local serif and sans-serif fallbacks work offline.

## Case study materials
The supplied reference images informed the visual direction. Case covers are original illustrative mockups, not final redesign screenshots. The Disney+ and TruFru redesign files and Beli and Duolingo slide decks are pending. Case dialogs explicitly mark missing materials; no scores, results, or external prototype links have been invented. Add final assets in `assets/` and update the study entries in `app.js` when available.
